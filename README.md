# MOMO · 原創全彩電子寵物 MVP

這是一款原創、可在瀏覽器或 Mac 進行測試的全彩電子寵物。互動節奏參考 Tamagotchi Uni，但不使用 Bandai 角色、商標或產品素材；Catode32 只作開源技術研究參考。

公開 Preview：<https://tamagotchi-uni-inspired-virtual-pet.vercel.app>

## 網頁原型 v0.3：主畫面直達操作

- 240×240 全彩寵物畫面，**螢幕下緣固定五個可點擊的快捷功能**：餵食、玩耍、清潔、睡覺／喚醒、狀態。一般照顧無須開主選單。
- 螢幕右上角保留「完整選單」，提供其他互動、狀態及設定。選單項目可以直接點擊，重設必須確認。完整選單的主要照顧動作不再有額外分類層級。
- A/B/C 三個實體形式按鍵仍可用：A 開啟選單／輪選，B 確認，C 返回／取消正在播放的動作。鍵盤 A/B/C 或 J/K/L 也能操作。
- 餵食、玩耍、清潔、休息、摸摸等操作採 **動畫時間軸**，包含準備→動作→反應；搭配姿勢切換、身體微動作、表情及粒子效果。睡眠和喚醒有各自的轉場。
- 支援系統減少動態效果設定；照顧動畫播放中暫時停用重複操作以防連點。
- 沿用既有瀏覽器本機存檔 key，保留 v0.2 已有的玩家進度；補上清潔數值（舊存檔缺少時採初始值）。狀態頁直接顯示主要數值。

## 已知限制

- 這一版是 **Web 互動原型**，動畫是有限姿勢、CSS 形變和裝飾粒子組成的階段式動作，不是完整逐格 Sprite Sheet 動畫。
- 尚未完成健康、個性 AI、成長分歧、物品背包、真實睡眠排程、完整離線推進與帶版本的存檔遷移。
- Web 的遊戲邏輯仍是 JavaScript，與 Rust 遊戲核心尚未完全共用；這一版只保留了操作邊界，不應將兩端視為相同遊戲規則。
- 尚無可燒錄 ESP32 韌體、原生 macOS app、雲端玩家存檔或完整板卡適配驗收。
- 角色姿勢仍是佔位素材，正式原創角色與逐格動畫需後續替換。

## 技術結構

- app.js：Web 模擬器、存檔、主畫面及動作狀態協調。
- navigation.js：A/B/C 導覽與可點擊選單共用選取語義。
- motion.js：與核心規則分離的動作時間軸，之後可換成真正逐格動畫。
- pet.js：目前 Web prototype 的暫時養成數值。
- firmware/：硬體無關的 Rust game-core、game-app、platform-api 骨架，尚非韌體映像。
- docs/：PRD v1.1 與 QA 驗收計畫。
- .github/workflows/ci.yml：Node 回歸測試與 Web 原型壓縮包。

## 本機執行

Apple Silicon Mac 可使用 Node 20+，無須外部 Node 套件，於專案目錄執行：

    npm test
    npm run serve

開啟 <http://localhost:4173>。目前沒有 Rust 編譯驗證證據；在本機環境中尚未安裝 cargo / rustc。

## 測試證據（v0.3）

- Node 回歸測試共 13 項，包含三鍵選單、直接選取、重設防誤觸、動作時間軸與養成數值。
- Mac 本機 headless Chrome UI smoke test：底部五鍵、餵食動作、狀態、返回、兩層選單、睡眠／喚醒及瀏覽器執行錯誤檢查均通過。
- 這些證據不等同 PRD M3 的所有 P0 驗收均完成。

以 PRD v1.1 的功能與驗收項目作為後續開發依據。
