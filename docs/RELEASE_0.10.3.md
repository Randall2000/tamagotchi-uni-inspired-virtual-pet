# v0.10.3｜幼貓虹膜變色修正與來源鎖定驗收

日期：2026-11-06

## 根因

前版的通用色盤比對將幼貓眼睛的深黃綠像素錯誤映射到食物道具的棕色。
例如原像素 (100,83,10)、(77,80,31) 被錯誤量化為 (118,68,38)。
之前只測試色盤數量、Alpha 與眼睛位置，沒有確認眼睛區域的顏色材質，因此錯色未被攔截。

## 修復

- 眼睛深橄欖色只允許選擇幼貓虹膜的黃綠色調色盤，禁止棕色色票污染。
- 臉部區域明確排除食物碗棕色、毛線球桃紅與飲水青色。
- 虹膜色彩直接以公認的幼貓原圖 public/assets/momo-kitten.png 為參考，恢復亮黃綠眼色與原有深色瞳孔。
- 睜眼與閉眼判斷改用量化前的原始像素，避免半閉眼誤判為睜眼。
- 重新輸出幼貓 1024×1024 母圖和 19 組日常動作素材，保持 64×64 邏輯像素格、128×128 輸出格、最多 32 色及二值透明。
- 成年貓圖集、角色身形、原始母圖、遊戲存檔、A/B/C 操作、非觸控顯示不變。
