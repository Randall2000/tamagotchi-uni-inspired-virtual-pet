# v0.8 一鍵動作、像素介面、didi

依 2026-11-05 回饋調整。

## 變更

- **照顧不再多一層選項**：底列改為 餐食、清潔、玩耍、摸摸、狀態、選單；前四個按 B 直接執行。選單只剩一層：睡覺、點心、洗臉、伸懶腰、看窗外、設定（B-INPUT-05）。
- **像素風介面**：選單項目、標題、計數、狀態列、提示列、長大畫面改為直角缺角像素框（上亮下暗）、像素箭頭；狀態頁數值條改為 10 格硬邊色塊，依高低變色（B-UI-01）。字型維持系統字、關閉反鋸齒。
- **改名 didi**：畫面、網頁標題、外殼字樣全部改為 didi；舊存檔的 MOMO 載入時自動改名（B-UI-02）。
- **閒置小動作**：不操作時每 6–12 秒隨機搖尾巴眨眼、舔爪子、東張西望或偶爾伸懶腰，使用現有影格、不改數值，任一鍵中斷（B-ANIM-08）。

## 驗證

- Node 測試 33 項通過：一鍵動作、單層選單、閒置動作挑選與頻率、閒置與所有動作相鄰影格位移 ≤1px。
