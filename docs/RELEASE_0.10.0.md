# v0.10.0｜幼貓／成年貓 19 組動作預覽整合

日期：2026-11-06

## 更新

- 以 `public/assets/momo-motions-preview/` 為現行動作來源，幼貓、成年貓各 19 組 PNG Sprite Sheet，共 38 組。
- 每格 128×128 px；每張 8 欄、2–4 列，依 manifest 播放 16／24／32 個時序影格，8／12 FPS。
- `motion-pack.js` 掌管動作 ID、別名、圖集與每格座標；`app.js` 依成長階段載入素材。
- 主畫面餵食、玩耍、清潔、摸摸，以及選單中的點心、喝水、如廁、睡前、睡眠、起床都能使用新圖集；待機情境可出現搖尾巴、好奇、生病、難過、開心等反應。
- 角色在照顧動作中固定錨點，不使用整張圖左右搖晃、旋轉或縮放製造假的動畫。走路是實際場景位移與步伐影格切換，不是待機晃動。
- 走路素材依年齡分別預先解碼，取消、散步完成和切回待機時都繼續使用同階段的 `idle.png`，避免閃回舊圖集。
- 保留原有 A/B/C 三鍵操作、不可點擊螢幕、本機遊戲進度與原始角色資產。
- 打包 GitHub Actions Web 測試產物時包含 `motion-pack.js`。

## 驗證

- `npm test`：包含 52+ 項自動測試，驗證圖集檔案、64 格舊素材、導航、數值、年齡和渲染契約。
- Mac Chrome 本機端到端測試：幼貓餵食、喝水、成年切換、睡著與起床通過，且無網頁載入錯誤。
- 素材 Alpha 與足底對齊檢查：各動作畫格足底偏差 0–1 px；圖格尺寸與 manifest 相符。

## 素材重要限制

這批 `momo-motions-preview` 是用原有圖集**重組的預覽素材**，不是每一格都經人工逐像素重畫，也不是數百格完全不同的動畫。有些 24／32 格動作只有 8 種獨立姿勢，睡眠甚至只有 3 種。睡姿、走路姿勢與部分表情仍需美術驗收；不得宣稱已完成最終版精準像素動畫。保留既有來源圖，不以放大、左右晃動冒充新的肢體動作。
