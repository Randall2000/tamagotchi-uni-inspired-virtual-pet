# v0.9.1 角色去背清理

2026-11-06。依回饋「角色未去背乾淨」。

## 問題
三張角色圖集（`momo-kitten-64-v2.png`、`momo-adult-64-v3.png`、`didi-walk-v1.png`）都有生圖留下的殘留：
- 每隻貓外圍一圈幾乎透明的深色陰影（每張 10–19 萬像素，透明度 1–31），放在房間上像灰霧光暈；
- 空白處散落的殘點，走路圖最多；
- 輪廓一圈半透明邊（3–5 萬像素），像素風應為硬邊。

## 修正
- 新增 `scripts/clean-sprites.mjs`：透明度 <128 清為完全透明，其餘補成完全不透明；每格中小於 20 像素的獨立碎點刪除；只改透明度、不改顏色，重跑結果不變（B-UI-04）。
- 三張圖集已清理並覆蓋原檔，檔案也變小（1.87→1.43 MB、1.69→1.24 MB、1.21→0.93 MB）。
- 新增測試：三張圖的透明度只有 0／255、沒有可再清的殘點，且遊戲用到的每張角色圖都納入清理。舊圖跑這組測試會失敗。

## 已知限制
成貓「玩毛線」那幾格，毛線球後方有一團畫進圖裡的紫灰色影子（不透明，顏色與毛色陰影重疊），透明度清理無法處理。已於 [v0.9.2](RELEASE_0.9.2.md) 重畫。

Node 測試 47 項通過。
