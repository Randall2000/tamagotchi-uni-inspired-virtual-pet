# v0.7 成長節奏與長大提示

依 2026-11-05 回饋「只做一個動作就突然變大貓」調整。

## 變更

- 成長門檻由 10／30 改為 **30／80**（B-BOND-03）。搭配 60 秒好感冷卻，最快約 14 分鐘進成長中、39 分鐘成年；一次照顧最多 +2，不會一次跳階段。
- 尺寸跳幅縮小：幼年 0.69 → 成長中 0.78 → 成年 0.88（原為 0.69 → 0.84 → 1.0）。成長中仍使用成貓圖（B-ANIM-10）。
- 長大演出：回到房間，角色 1.2 秒慢慢放大；慶祝畫面「MOMO 長大了！幼年 → 成長中」顯示 4 秒，任一鍵可提早關閉（B-ANIM-11）。
- 修正動作時角色位移：原本逐格以鼻子中心定位，頭一轉整隻貓就被拉著移動（相鄰影格最多 2.5px）。改為每個圖集一個固定定位點，相鄰影格位移 ≤1px，並新增自動量測測試（B-ANIM-12）。
- 舊存檔保護：v0.6 以前已達到的階段保留，不會因門檻提高而縮回小貓（B-BOND-06，存檔新增 `stageFloor`）。
