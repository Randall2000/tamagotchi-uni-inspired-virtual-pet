# didi｜遊戲數值表（唯一來源）

> 文件版本：1.6｜2026-11-05｜對應程式：Web 原型 v0.8.2（`pet.js`、`navigation.js`、`motion.js`、`app.js`）
> 規則：**所有遊戲數字以這裡為準**。[PRD.md](PRD.md) 只引用本表 ID；兩份驗收文件引用 ID，可在括號附上目前數值方便閱讀，不一致時以本表為準。改數值時，程式、本表、測試、驗收文件括號內的數值在同一個 commit 改。

「Web 現行」＝ v0.8.2 程式實際行為，可直接驗收。「Mac/硬體」＝尚未實作，標「待定」者須在對應里程碑平衡測試後回填。

## B-BOND｜好感與成長

| ID | 項目 | Web 現行 |
|---|---|---|
| B-BOND-01 | 範圍 | 0–100，永久累積，只增不減 |
