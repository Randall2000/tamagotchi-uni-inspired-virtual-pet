# v0.6 互動與畫面更新

依據使用者提供的研究規格與本次確認：維持永久關係度成長，加入防連按；不採文件的時間成長提案。

## 已實作

- 外框沿用原圖，以實際 1127×1396 尺寸計算。視窗 x321/y464/w479/h476；螢幕等比例置中。B 鍵點擊區對準較低的中間按鈕。
- 螢幕 240×240、不接受觸控；只用 A 選擇、B 確認、C 返回。按鍵有 A/B/C 標示及按下回饋。
- 底列：食物、清潔、玩耍、陪伴、狀態、選單。食物先看正餐／點心及效果，B 才執行；常用互動最多一個子選單。
- 互動完成／取消後恢復來源選單與焦點；失敗顯示原因。C 取消經過收勢，無照顧獎勵。
- 動作完成才結算一次；動畫中重複 A/B 不追加交易。120ms 輸入防抖；跨行為共用 60 秒關係加分冷卻並存檔，照顧數值仍可正常恢復。
- 主畫面五顆像素愛心，每顆 20 點，支援部分填色並保留 0–100 數字。狀態頁顯示需求條、距離長大的關係差額及加分冷卻。
- 關係 0–9 幼年、10–29 成長中、30+ 成年，需求降低不會縮小。不再以餵食產生金幣。
- 已滿飽足時拒絕正餐；不需要點心時拒絕點心；精力不足拒絕玩耍；已乾淨拒絕清潔。梳洗確實增加清潔值。
- 需求下降保留小數，修正每分鐘取整導致需求不減的問題；睡眠按分鐘恢復精力。
- 離線補算最多 240 分鐘，時間回撥不倒退；睡眠和關係冷卻存檔保留。
- 狀態提示固定於房間和功能列之間，不覆蓋角色。熟睡可 B/C 喚醒。
- 幼貓與成年各 64 格動畫，主要動作 8 個不同姿勢，約 4–5.2 秒，增加尾巴與臉部／四肢變化。詳見 ANIMATION_V2.md。
