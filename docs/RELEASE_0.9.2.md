# v0.9.2 重畫成貓玩毛線 8 格

2026-11-06。接續 v0.9.1 的已知限制。

## 問題
成貓圖集第 24–31 格（玩毛線），毛線球和身體之間有一團霧霧的紫灰色：實際上是伸向毛線球的前腳和球後方地面，被畫成了混濁的紫灰色，看起來像沒去乾淨的影子。這個顏色在其他動作是正常的毛色陰影，不能整張圖用顏色刪。

## 修正（`scripts/fix-yarn-shadow.mjs`）
只處理這 8 格的左下區塊：
- 毛線球中心**右側**的紫灰色（前腳、身體側邊）補成黑毛色；
- 毛線球中心**左側**落在地面的紫灰色清成透明，碰到毛線的轉成深色外框，讓細細的線尾保持完整；
- 毛線球左側補齊外框，封住 1px 缺口，最後再跑一次去背清理。
重跑時偵測到已修過就不寫檔。

## 驗證
- 8 格紫灰色區塊像素：修前 241–507／格，修後 0。
- 新增測試「成貓玩毛線沒有紫灰影子」，修前會失敗；Node 測試 48 項全過。
- 逐格放大比對與房間實際畫面確認（成年第 29 格）。
