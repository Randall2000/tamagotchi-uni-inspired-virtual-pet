# v0.10.5｜重抓色票、像素精修、整數倍顯示

日期：2026-11-06。依回饋「pixel 邊緣有問題、顏色會混色，重新抓色票重新設定 QA」。

## 根因
1. **圖裡的抖動雜點**：32 色裡有 4 組肉眼分不出的近似色（兩種描邊黑、兩種黑毛、兩種黃綠眼、純白與米白），在毛上交錯出現像雜訊；腳趾上還混了水碗的藍色；輪廓有零星凸點、缺口和非描邊色。
2. **非整數倍放大**：角色每格 64 個像素格，在 375 寬、2 倍密度的手機上，每格落在 2.66 個實體像素，有的 2px 有的 3px，邊緣粗細不一。

## 修正
- **色票 v1**：24 色，任兩色 ΔE ≥ 10，每色標用途（[PALETTE.md](PALETTE.md)）。
- **`scripts/pixel-polish.py`**：套色票、清孤立雜點、身上零星道具色改回周圍材質、補 1 格缺口（腳趾間除外）、實心區塊外框統一描邊色；反覆到不再變動，重跑 0 改動。已套用到 40 張角色圖。幼貓眼睛位置與鎖定的黃綠色不變。
- **整數倍顯示**：`petPixelSizes()` 依螢幕縮放與密度算出每格的整數實體像素數；375@2 手機 3 倍、375@3 幼 4／成 5、桌機 2 倍密度幼 4／成 5。
- **QA 重訂**：驗收清單新增 2.7「像素與色票」WEB-PX-01～08；新增 42 項自動測試；舊的 WEB-ANIM-06／07 由新條件取代。

## 驗證
- `npm test`：108 項全過（含新 42 項；舊圖跑新測試 40 張全失敗）。
- 本機 375×812（2 倍）：`data-device-px-per-art-px` = 3,3，角色寬 × 2 ÷ 64 = 3.000；1:1 截圖每格同寬。

## 限制
- 房間背景是一般插畫，不在角色色票範圍，邊緣仍可能看起來較柔。
- 375 寬 2 倍密度的手機上，幼貓與成貓同尺寸（3 倍）；否則幼貓得縮到 2 倍（81px）。
- 1 倍密度且視窗很窄時，只能選 1 或 2 倍。
