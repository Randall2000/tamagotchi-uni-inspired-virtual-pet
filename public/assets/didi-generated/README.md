# didi 生圖動作素材

使用者核准角色外觀後，依 `docs/ART_SPEC_CHATGPT.md` 製作幼貓與成貓各 19 個動作，每個動作 8 個主要影格。全部為 PNG 點陣圖。

| 路徑 | 內容 |
|---|---|
| `character/` | 核准外觀的幼貓、成貓設定圖副本 |
| `raw/` | ChatGPT 原始生圖，包含待機修訂版；保留原檔供追溯 |
| `normalized/` | 固定 32×32 邏輯格、色票與整數座標後的 4×4 來源圖 |
| `review/kitten/`、`review/adult/` | 收圖工具輸出的 8×128px 遊戲格式候選圖；**尚未載入遊戲** |
| `action-overview.png` | 38 個動作第一格的總覽與驗收狀態 |

目前自動收圖結果：幼貓 2／19 通過、成貓 1／19 通過。其餘 35 張的缺陷編號見 `art/action-intake-summary.json`。通過的是幼貓 `idle`、`sleep` 與成貓 `idle`，且只代表轉檔後的技術檢查；仍需逐格目視檢查動作、四肢與花色。原始生圖本身不是遊戲可直接使用的素材。
